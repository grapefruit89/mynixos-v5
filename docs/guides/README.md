# Guides Index

Dieses Verzeichnis enthält die konsolidierte Dokumentation für das NixHome v7.1 Strict Projekt. Alle Guides folgen einem nummerierten Schema (00-90) für optimale Sortierbarkeit und Themenfokus.

- **[50-monitoring-stack.md](./50-monitoring-stack.md)**: Health-Checks (Gatus), System-Telemetry (Netdata) & Logging-Infrastruktur.
- **[60-media-stack.md](./60-media-stack.md)**: Video (Jellyfin), Audio (Navidrome), Books (Audiobookshelf) & Download-Management.
- **[70-knowledge-automation.md](./70-knowledge-automation.md)**: Dokumenten-Management (Paperless), Sync (OCIS) & Automation (n8n).
